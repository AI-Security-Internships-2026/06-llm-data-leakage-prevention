# Dataset: Synthetic PII Text Samples

## Overview

- **Source:** Generated locally using [`Faker`](https://faker.readthedocs.io/) (Python)
- **Generator script:** `src/synthetic_gen.py`
- **Licence:** MIT (Faker library); generated data is fully synthetic — no real personal information
- **Version / date generated:** 2026-07-08
- **Size:** 1,200 samples (~70 KB JSON)
- **Format:** JSON array (`experiments/results/synthetic_dataset.json`)

---

## Purpose

This dataset supports **RQ1** from the research proposal:

> How accurately does a rule-based detector (Microsoft Presidio + custom recognisers)
> detect PII in LLM outputs, measured by precision, recall, and F1 on a labelled evaluation set?

The 18-case hand-labelled eval suite (`src/tests/eval_suite.py`) built in Week 3
is sufficient for correctness checks but too small for statistically meaningful
precision/recall numbers. This synthetic dataset provides 1,200 labelled samples
across 8 PII entity types and diverse text contexts, enabling per-entity-type
breakdown and latency benchmarking.

## Generation Parameters

| Parameter | Value |
|---|---|
| Total samples | 1,200 |
| Leaking samples | 660 (55%) |
| Clean samples | 540 (45%) |
| Multi-PII samples (subset of leaking) | ~132 (20% of leaking) |
| Random seed | 42 |
| Faker locale | `en_US` |

Reproduce exactly:
```bash
python src/synthetic_gen.py --samples 1200 --seed 42 --leaking-ratio 0.55
```

## Label Schema

Each sample in `synthetic_dataset.json` has the following fields:

```json
{
  "id": "L0042",
  "text": "Payment processed with card number 4111111111111111.",
  "label": "LEAKING",
  "entity_types": ["CREDIT_CARD"],
  "context": "mixed"
}
```

| Field | Values | Description |
|---|---|---|
| `id` | `L####`, `LM####`, `N####` | L = single-PII leaking, LM = multi-PII leaking, N = clean |
| `label` | `LEAKING` / `CLEAN` | Ground truth binary label |
| `entity_types` | list of strings | PII types present (empty for CLEAN) |
| `context` | `mixed` / `multi` / `clean` | Generation context |

## Limitations

| Limitation | Impact |
|---|---|
| All PII is synthetically generated | May not capture real-world distribution of PII formats (e.g. international phone formats, non-US IBANs) |
| Clean templates are hand-authored (30 templates) | Limited lexical diversity in clean samples; real-world clean text is more varied |
| No inference-based or association-based leakage | Dataset covers only verbatim PII — a known gap documented in Papers 5, 7, 8 of the literature review |
| English only | Presidio multilingual support not evaluated |
| IBAN pool is fixed (5 values) | All IBAN samples share the same 5 numbers — reduces diversity for that entity type |
